## Speed and polish follow-ups (2026-09-29, after the fix/open-work merge)

Cause analysis by a read-only profiling pass on Bigfox (about 0.45 ms per COM call; the time is almost entirely cross-process round trips), then fixes on branch `perf/round2` (streams F, G, H). Verified live on Bigfox against a build of the pre-change code: element-ID sets are identical on 20 screens (Easy Access, ST22, SM37, RZ11, SU01, SM50, RZ04, SE16 with its pre-selection subscreen, SE11 with tabs and a table control, SEGW, the Gateway service grid, SE38, SE80, SM59, SICF), and all earlier live checks still pass. 242 Catch2 test cases pass (1724 assertions).
